## 简历 Bullet（Agent 开发视角）

**项目：AI 面试模拟 Agent（个人全栈项目）**

- **自主实现 ReAct Agent 框架**（不依赖 LangChain）：推理-行动-观察循环、工具调用、记忆持久化，支持串行管道 / 并行汇总 / 多方辩论三种**多 Agent 编排**模式——面试官追问、简历解析、报告生成等环节均为独立 Agent 协作。
- **混合 Agent 架构（关键设计）**：状态机管骨架（7 状态面试流程）+ **FollowUpAgent 管自主决策**——LLM 结合题目/回答/历史追问自主判断是否追问、追什么；三级降级链（确定性边界 → Agent → 规则兜底）保可靠——**追问贴题率 0%→100%**（30 样本评测）。
- **RAG 检索增强**：**519 条面经**（内置 22 + 知识库 397 + LeetCode 官方题解 100），自研轻量检索器（关键词 Jaccard + 字符 n-gram，零向量库依赖、可平替 ChromaDB），参考答案**检索增强生成**——长度 36→**144 字**、信息密度 +174%、面经覆盖题库 **72.5%**。
- **记忆与个性化**：轮内摘要（历史追问可"翻旧账"）+ **跨会话能力画像**（每技能均分/强弱项/进步趋势），画像弱项自动注入下一场面试的追问决策，形成「画像驱动的个性化面试」闭环。
- **LLM 工程化**：多 Provider 统一适配（OpenAI/Anthropic/Ollama）+ 结构化输出 + Prompt Caching；**指数退避重试 + 熔断器 + 三级降级链**应对 LLM 抖动；SSE 流式报告；全链路 token/成本/延迟埋点——**输入 token 减少 70%**、单场 8 题面试实测成本 **≈¥0.02**（真实 DeepSeek，随追问深度波动 ¥0.02-0.05）、单次评估 17.6s→**5.4s**（asyncio 并行）。
- **量化评测闭环（LLM-as-judge）**：自建 30 样本人工标注评测集，评分 **MAE 0.94 / Pearson 0.991 / 一致性 std 0.16**；评测驱动真实修复（中文关键词匹配缺陷，MAE 1.50→0.94）——**评测不是口头说"效果好"，而是可复现的数字**。
- **工程能力佐证**：**261 个测试**（覆盖率 87%，CI 门禁 80%）、Docker Compose 一键启动、判题子系统（AST 安全审计 + subprocess 隔离，100 道 LeetCode 中 69 道自动生成用例，无自动用例的题降级 AI 代码评审、0 用例拒绝执行防假阳性）。

## 高频追问预案（Agent 岗）

- **为什么不直接用 LangChain？** 面试场景需要讲清每一步——自主实现 ReAct 才能展示对 Agent 循环（推理-行动-观察）、工具调用、记忆管理的理解；框架是黑盒，面试会被认为"调包"。
- **你的 Agent 怎么自主决策？** 混合 Agent：状态机管骨架（确定性流程），FollowUpAgent 管自由度（是否追问、追什么由 LLM 结合题目/回答/历史追问自主判断），三级降级（规则兜底）保证 LLM 不可用时流程不断。
- **怎么保证 Agent 输出格式稳定？** 结构化输出（JSON Schema 约束）+ 输出校验器 + 截断 JSON 修复（`repair_truncated_json`）+ 非法枚举安全回退——真实 LLM 模式枚举解析崩溃会让整场面试挂掉，所以每个边界都有兜底。
- **RAG 为什么不用向量库？** 项目体量下关键词 Jaccard + 字符 n-gram 足够且零依赖、可解释；接口先行设计，装 ChromaDB 可平替向量检索——先解决"有没有"，再谈"精不精"。
- **遇到 LLM 抖动/超时怎么办？** 指数退避重试（含 jitter）+ 熔断器（三态：关/开/半开）+ 三级降级链（LLM → 规则 → 缓存兜底），全程留日志可观测——面试中体现的是对真实生产风险的预判。
- **你的评测怎么证明有效？** 三件套全离线可复现：benchmark（规则覆盖率/判题检出）+ judge_eval（LLM-as-judge 评分质量）+ feature_eval（功能 Before/After）——每个数字都能一键重跑，不靠口头描述。
- **代码题怎么判（工程能力）？** 不是 LLM 主观评价——AST 白名单审计 → subprocess 隔离 → 真实测试用例 pass/fail；100 道 LeetCode 中 69 道自动生成用例（链表/树注入节点类 + 构造/序列化器）；无自动用例的题降级 AI 代码评审，0 用例直接拒绝执行（杜绝空用例判 AC 假阳性）。
