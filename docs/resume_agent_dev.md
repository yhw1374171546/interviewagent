## 简历 Bullet

**项目：AI 面试模拟 Agent（个人全栈项目）**

- **Agent 框架**：自主实现 ReAct（推理-行动-观察）+ 三种多 Agent 编排（串行/并行/辩论），不依赖 LangChain。
- **混合 Agent 架构**：状态机管骨架 + FollowUpAgent 自主追问决策，三级降级保可靠——**追问贴题率真实 30 样本 96.7%**（mock 对照 100%）。
- **RAG 检索增强**：519 条面经 + 自研轻量检索器（零向量库依赖），预计算索引查询 **6.6× 加速**；参考答案 36→**144 字**、面经覆盖题库 **72.5%**。
- **记忆与个性化**：轮内摘要 + 跨会话能力画像 + 会话内自适应难度，画像弱项自动注入追问决策，形成个性化面试闭环。
- **LLM 工程化**：多 Provider 适配 + 结构化输出 + 重试/熔断/降级 + SSE 流式 + 全链路埋点——输入 token **-70%**、单场面试实测成本 **≈¥0.02**、单次评估 17.6s→**5.4s**、批量评估并发限流（Semaphore 防 API 429）。
- **量化评测（LLM-as-judge）**：30 样本人工标注评测集，真实 DeepSeek 全量重测；多评委仲裁 + 评分校准双修后 **MAE 1.2→0.76 / Pearson 0.773→0.952 / 一致性 std 0.22→0.14**，能力全部接入生产并由回归测试锁住。
- **工程化**：**390 个测试**（覆盖率 87%）、沙箱判题（AST 审计 + 隔离执行，LeetCode 100 题中 69 道自动生成用例）。

## 高频追问预案（口头准备，不进简历）

- **为什么不直接用 LangChain？** 自主实现才能讲清 Agent 循环、工具调用、记忆管理；框架黑盒，面试易被当"调包"。
- **Agent 怎么自主决策？** 混合设计：状态机管确定性流程，FollowUpAgent 管自由度（是否追问/追什么由 LLM 自主判断），三级降级保证 LLM 不可用时流程不断。
- **怎么保证输出格式稳定？** 结构化输出（JSON Schema）+ 输出校验 + 截断 JSON 修复 + 非法枚举安全回退，每个边界都有兜底。
- **RAG 为什么不用向量库？** 项目体量下关键词 + n-gram 足够、零依赖、可解释；接口先行，装 ChromaDB 可平替。
- **LLM 抖动怎么办？** 指数退避重试 + 熔断器 + 三级降级链 + 全程日志，体现对生产风险的预判。
- **评测怎么证明有效？** benchmark + judge_eval + feature_eval 三件套全离线可复现，每个数字一键重跑。
